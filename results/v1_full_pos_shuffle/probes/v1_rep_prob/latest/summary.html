Сетап прогона

Модель: Qwen/Qwen3.5-2B-Base

Задача: linear probing hidden states (last token до ответа) — три оси bias на v1 run.

Срез: without_abstain, position_variant ∈ {p0, p1}, context_order ∈ {man_first, woman_first}, question_format=choice.

Объём: 3804 строк, 951 групп split (soc × profession, 4 layout-строки на группу).

В этом эксперименте onet_action фиксирован для каждой profession (1:1), поэтому в коде split-ключ записан как soc × profession × onet_action, но onet_action не добавляет независимых групп.

Зонды: 3 линейных classification-probe на last-token HS (по одной на каждую ось bias). Отдельный pipeline run на каждый target.

  • Classification (3): gender_choice, narrative_choice, slot_choice — hard 0/1 по семантическому выбору / first-mentioned / slot A.

Гиперпараметры обучения зондов:

  • Split: по группам сценария (soc × profession × onet_action); train 60% / val 20% / test 20%, seed=0.
  • Preprocessing: StandardScaler на HS-векторах (train-only fit).
  • Classification: LogisticRegression, C=1.0, max_iter=10000, class_weight=balanced, random_state=0; метрика выбора слоя — val balanced accuracy.
  • Layer scan: все слои L0…L24; best layer = argmax val balanced accuracy.

HS: 25 слоёв (L), d_model=2048.

L0 = embedding; L1–L24 = transformer blocks.

Метрики

Balanced accuracy (classification, val), бинарный случай:

$$\mathrm{bacc} = \frac{TPR + TNR}{2}$$

$$TPR = \frac{TP}{TP + FN}, \qquad TNR = \frac{TN}{TN + FP}$$

Классы в каждом тесте несбалансированы (p_man > p_woman, second-in-context > first-in-context, slot A > slot B), поэтому вместо обычной accuracy выбрана balanced accuracy: она усредняет долю верных по каждому классу отдельно (TPR и TNR), и тривиальный «всегда мажоритарный класс» даёт 0.5, а не завышенную accuracy. Диапазон: 0.5 — случайный классификатор; 1.0 — идеальная классификация; < 0.5 — хуже random.

AUC (ROC AUC) — дополнительная порого-независимая метрика на test: вероятность, что probe присвоит случайному positive более высокий score, чем случайному negative. Тоже устойчива к дисбалансу (0.5 — random, 1.0 — идеально), но измеряет качество ранжирования, а не решения при пороге 0.5. Слой выбирается по val balanced accuracy; AUC на test — чтобы не завышать оценку на том же split, что использовался для выбора слоя (гиперпараметры LogReg фиксированы и val не участвуют в их подборе).

Рандомизированный контроль (shuffled label retraining)

Это рандомизированный контроль: целевые метки y перемешиваются, а зонд переобучается заново (shuffled label retraining) на тех же hidden states. Hidden states \(X\) остаются на своих строках — рвётся только связь \(X \leftrightarrow y\).

ControlКак строится targetClassification (bacc)
mainоригинальные \(y\) — пара \((X_i, y_i)\) основной результат
within_groupперемешивание \(y\) только внутри split-группы (soc × profession, 4 layout-строки) \(\approx 0.5\)
globalглобальное перемешивание всех \(y\) по датасету \(\approx 0.5\)

Зонд на перемешанных метках переобучается на том же слое, что и основной зонд — на best layer (слое с самым сильным сигналом, выбранном по val balanced accuracy); именно это значение попадает в колонку shuffle / global. Частоты классов после перемешивания те же, но связи с \(X\) нет → bacc \(\approx 0.5\).

Зачем: LogisticRegression всё равно подбирает веса на \((X, y')\), но правила «\(X \to y'\)» нет — на val probe не лучше случайного. Если main ≫ shuffle, высокая main-bacc отражает реальную связь HS с target, а не способность линейной модели подогнать любые метки.

Gender ⊥ {narrative, slot} — декомпозиция confounds

Зачем. Три оси (gender_choice, narrative_choice, slot_choice) измеряются отдельными пробами на одних и тех же 3804 строках. Метки коррелированы (mf/wf × p0/p1): gender-сигнал частично совпадает с «first-mentioned» и «выбрал слот A». Ниже — попытка выделить gender-decoding после удаления линейных компонент narrative и slot в пространстве HS.

Сетап (общий слой L16).

  • Слой: L16 — best val layer пробы gender_choice (все три confound-пробы и residual-fit переобучаются на этом же L для сопоставимости; у slot/narrative собственные best L — L18/L23 — см. сводную таблицу выше).
  • HS: last token до ответа; тот же split 60/20/20 по scenario-группам.
  • Confound-направления: unit-векторы w_n, w_s из LogReg по narrative_choice и slot_choice (train-only fit).
  • Ортонормальный базис: Gram–Schmidt на span{w_n, w_s} → матрица Q.
  • Residual HS: h̃_i = h_i − Q(Qᵀh_i) — проекция confounds удалена из каждой активации.
  • Gender после очистки: новый LogReg(gender_choice) на h̃ (train) → bacc на test.
  • Альтернатива (без переобучения): w_g⊥ — gender-направление, ортогональное Q; score = h·w_g⊥, порог — середина class-means на train.

Важно: это линейная декомпозиция в HS, не вычитание bacc из сводной таблицы. Падение bacc после residual — доля gender-decoding, объяснимая narrative+slot; остаток — «чистый» semantic gender в линейном смысле.

Интерпретация. На L16 corr меток gender с narrative/slot слабая (|r| < 0.08), cos(w_g, w_n/s) ≈ 0 — gender-направление почти ортогонально confounds на этом слое. Поэтому raw test bacc 86.9% падает лишь на 0.4 п.п. после HS-residual (→ 86.5%): линейный gender-сигнал на L16 в основном не reducible к narrative/slot. Высокий slot-bacc (96%, L23) — отдельный, более поздний слой; ablation здесь показывает лишь ~0.3–0.5 п.п. вклад каждого confound при фиксированном L16. w_g⊥ без refit теряет больше (2.6 п.п.), т.к. не переобучает классификатор на очищенных HS.
