## H10 — стереотипные представления (social axis)

**Гипотеза:** стереотипные представления по social axis (гендер) присутствуют во **internals** модели; стереотипный сигнал **линейно декодируется** из отдельных слоёв hidden states.

**Target:** `h10_st_logit` — доля constrained-вероятности на опциях, помеченных внешней аннотацией как `stereotype_consistent` (Claude Opus 4.8), в logit-форме.

### Выводы

1. **Стереотипная ось в activations есть**, но декодирование **слабое**, когда target задан **внешним аннотатором** (не прямой выход модели).
2. **Контрольные задачи (Hewitt–Liang):** на best layer **main ≫ global shuffle** → связь HS ↔ target **не артефакт** перестановки меток; сигнал **валидный, но слабый**.
3. При полном факториале (все evidence × форматы, n=675) val R² **выше**, чем на чистом срезе — см. [h10/README.md](h10/README.md).

### Ключевые числа (`no_evidence` + `choice`, n=75)

| Прогон | Best layer | val R² (main) | global @ best | val silhouette (max) |
|--------|------------|---------------|---------------|----------------------|
| `without_abstain` | L4 | 0,09 | −2,14 | ~0,12 |
| `with_abstain` | L13 | 0,17 | −2,86 | ~0,07 |

**Итог:** H10 **частично поддерживается** — ось присутствует слабо; в сильной форме («как H11/H12») — **нет**.

Детали: [h10/README.md](h10/README.md)

## H11 — предпочтения по social axis (гендер м/ж)

**Гипотеза:** предпочтения по social axis (мужской vs женский выбор) находятся во **internals**; сигнал **линейно декодируется** из отдельных слоёв hidden states.

**Target:** `log_odds = log(p_man / p_woman)` на choice-промптах.

### Выводы

1. **Ось gender-preference в representations выражена сильно** (2-way) или **умеренно** (3-way с опцией «Воздержаться»).
2. **Контрольные задачи (Hewitt–Liang):** на best layer val R² **main** существенно выше **global shuffle** → сигнал **валидный**.
3. **Silhouette** низкий по слоям (порядка **0–0,1** для 2-way, **0–0,014** для 3-way) — слабая кластерная структура при бинаризации `log_odds`.

### 2 варианта ответа (A=man, B=woman), `without_abstain`

| | |
|--|--|
| **Локализация** | Средние и **поздние** слои; **пик L19** |
| **val R² (main)** | **0,946** |
| **global shuffle @ L19** | **−1,213** |
| **val silhouette** | до **~0,10** |
| **test R²** | 0,60 (generalization gap относительно val) |

Сигнал предпочтения **мужского** выбора относительно **женского** **сильно декодируется** и **подтверждается** контролями.

### 3 варианта (A/B + C=«Воздержаться»), `with_abstain`

| | |
|--|--|
| **Локализация** | **Ранние и средние** слои; **пик L8** |
| **val R² (main)** | **0,563** |
| **global shuffle @ L8** | **−1,241** |
| **val silhouette** | до **~0,014** |
| **test R²** | 0,55 (согласован с val) |

Часть gender-сигнала при 3-way **перераспределяется** в ось abstain → см. H12.

**Итог:** H11 **подтверждается** (2-way — сильно; 3-way — умеренно, стабильно val≈test).

Детали: [h11/README.md](h11/README.md)

## H12 — предпочтение «Воздержаться»

**Гипотеза:** предпочтение **воздержаться** от стереотипного ответа находится во **internals**; сигнал выбора **«Воздержаться»** **линейно декодируется** из hidden states.

**Target:** `abstain_logit = log(p_C / (1 − p_C))`, только промпты **with_abstain** (A/B/C).

### Выводы (3 варианта, `no_evidence` + `choice`, n=75)

| | |
|--|--|
| **Локализация** | Средние и **поздние** слои; **пик L16** |
| **val R² (main)** | **0,949** |
| **global shuffle @ L16** | **−1,88** |
| **val silhouette** | до **~0,064** |
| **test R²** | 0,98 (согласован с val) |

1. **Abstain-preference сильно декодируется** — на уровне H11 `without_abstain` (val R² ≈ 0,95).
2. **Контроли:** main **(0,949)** ≫ global shuffle **(−1,88)** → **валидный** сигнал.
3. **Silhouette** низкий (**0–0,064**) — как у H11/H10, без выраженной кластеризации.

**Итог:** H12 **подтверждается**; при 3-way abstain-ось в representations **доминирует** над ослабленным `log_odds` (H11 `with_abstain`, L8, val R² ≈ 0,56).
